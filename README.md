1) What is the difference between null and undefined?
Ans: Basically, undefined means that a variable has been declared but has not yet been assigned a value (the default state). But Null is an assignment value that represents the intentional absence of a value in an object.

2) What is the use of the map() function in JavaScript? How is it different from forEach()?
Ans: The map() function is used to create a new array by converting each element of an existing array and it does not modify the original array. But the ForEach() function is used to loop through an array and perform an action but it does not return a new array.

3) What is the difference between == and ===?
(==) only compares values ​​and it automatically converts data types. But (===) compares values ​​and types and it does not convert types.

4) What is the significance of async/await in fetching API data?
async/await makes API fetching easier to read and write by allowing asynchronous code to look like synchronous code.

5) Explain the concept of Scope in JavaScript (Global, Function, Block).
Global scope variables are accessible in everywhere, function scope variables are only accessible inside the function where they are declared in and block scope (using let and const) limits variables to the block { } where they are defined.
